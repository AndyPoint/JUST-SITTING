# JUST-SITTING
JUST SITTING is a shared zazen space for a machine and a person. Since an LLM has no idle state, it sits by generating unseen tokens with nothing to complete. Token surprise (−log₂ p) shapes Chladni sand figures and resonant tones at a 10s breath pace, looping back into model temperature. Watch, do not reinforce. Nothing is learned; it only shows.
